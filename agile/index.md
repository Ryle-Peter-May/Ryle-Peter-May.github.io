# Agile Project Portfolio

This section documents the project I worked on over the last six months.

## Project overview


|---|---|
| **Project name** | SAFEGUARD |
| **Duration** | *July – October 2026* |
| **Team size** | *5* members |
| **My role** | Team Lead/Developer |
| **Tools** | Trello, GitHub, Supabase |
| **Live link / repo** | *https://safeguard-kanon9.vercel.app* |
| **Trello Link** | *https://trello.com/b/aCuzANQ9/safeguard* |

This project is a community-based security platform for Soshanguve township in Pretoria, pairing locally recruited, PSIRA-trained guards with a mobile app where residents send a one-tap emergency alert to the nearest guard. It is built for township households and small businesses that are priced out of, or overlooked by, large private security companies like ADT and Fidelity. By offering a R100 to R200 monthly membership, it addresses high crime and slow emergency response while creating jobs for local youth.
